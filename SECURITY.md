# Security

If you find a security problem in Aurox Admin, please don't open a public issue.

Report it privately through GitHub instead: go to the **Security** tab of this repository and click **Report a vulnerability**. Include the version you're on, what you found, and how to reproduce it.

I'll reply as soon as I can, work on a fix, and credit you in the release notes if you'd like.

## Supported versions

Only the latest release gets security fixes. Please update before reporting.
